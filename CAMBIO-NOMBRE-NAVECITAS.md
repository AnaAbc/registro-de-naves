# Cambio de nombre comercial: Navecitas

Se actualizó la marca visible del prototipo de **Navesitas** a **Navecitas** en títulos, cabeceras, metadatos de páginas, textos de interfaz, correos del sistema, encabezados visuales y referencias descriptivas de documentación.

## Compatibilidad

Por seguridad y para no interrumpir instalaciones existentes, **no se renombraron**:

- Las cuentas demostrativas `@navesitas.pa` ni la contraseña de prueba ya existente
- Las variables y propiedades técnicas `NAVESITAS_*` y `navesitas.*`
- Las claves de sesión del navegador y los nombres de Docker, volúmenes y usuario del contenedor
- Los paquetes y rutas internas de código, las migraciones de Flyway ni los reportes históricos de pruebas
- El nombre del repositorio de GitHub (`registro-de-naves`) ni sus referencias

Este cambio es de identidad visual y textual; no modifica el flujo del registro, roles, API ni permisos.
